# Archive

Older versions of the JUPAS calculator (2020–2025) and historical data snapshots.

These aren't kept in the repository itself — they're large, year-on-year source
files that would bloat every clone — so they live as **downloadable assets on the
[`archives` release](https://github.com/JUPASCal/JUPASCal.github.io/releases/tag/archives)**.
Nothing is lost: a future maintainer can pull any year down for reference.

Each archive is a `.tar.gz`. Click to download:

|------|---------------|----------|
| 2020 | 2020 JUPAS 計分器 | [archive-2020.tar.gz](https://github.com/JUPASCal/JUPASCal.github.io/releases/download/archives/archive-2020.tar.gz) |
| 2021 | 2021 JUPAS 計分器 | [archive-2021.tar.gz](https://github.com/JUPASCal/JUPASCal.github.io/releases/download/archives/archive-2021.tar.gz) |
| 2022 | 2022 JUPAS 計分器 | [archive-2022.tar.gz](https://github.com/JUPASCal/JUPASCal.github.io/releases/download/archives/archive-2022.tar.gz) |
| 2023 | 2023 JUPAS 計分器 | [archive-2023.tar.gz](https://github.com/JUPASCal/JUPASCal.github.io/releases/download/archives/archive-2023.tar.gz) |
| 2024 | 2024 JUPAS 計分器 | [archive-2024.tar.gz](https://github.com/JUPASCal/JUPASCal.github.io/releases/download/archives/archive-2024.tar.gz) |

> The repository's pre-reset git history is also preserved separately by the
> maintainer (a `git bundle` of the full history). Ask if you need it.

To extract any archive:

```bash
tar xzf archive-2025.tar.gz
```
